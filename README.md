# SchedNova

SchedNova is a modern React + Vite SaaS platform for AI-assisted timetable generation.

## Features

- Firebase authentication with email/password and Google login
- Role-aware dashboard for Admin, Teacher, Student, Personal User
- Multi-step setup wizard for institute, teachers, subjects, sections, and constraints
- Smart scheduling engine with greedy/backtracking-based timetable generation
- Calendar-based timetable preview with export to PDF/image support
- Responsive design, dark/light-ready UI, and interactive dashboard components

## Tech stack

- React + Vite
- Tailwind CSS
- Firebase Auth + Firestore
- Redux Toolkit
- React Router DOM
- React Hook Form + Zod
- Framer Motion
- React Big Calendar
- React Beautiful DnD
- jsPDF + html2canvas
- React Hot Toast
- Lucide React Icons
- date-fns

## Getting started

1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Open `http://localhost:4173`
